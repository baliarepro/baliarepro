Masuk

Halaman ini menyimpan perubahan langsung ke website lewat GitHub. Masukkan kunci akses GitHub (token) satu kali di HP ini.

Cara membuat token (sekali saja, ±3 menit)
  1. Login GitHub dengan akun baliarepro, lalu buka github.com/settings/personal-access-tokens/new.
  2. Token name: Admin website. Expiration: pilih 1 tahun (atau sesuai keinginan).
  3. Repository access: pilih Only select repositories → baliarepro/baliarepro.
  4. Permissions → Repository permissions: Contents = Read and write. (Opsional: Actions = Read-only, supaya status update terlihat di sini.)
  5. Klik Generate token, salin, lalu tempel di kolom di atas.

Token hanya tersimpan di browser HP ini. Jangan dibagikan ke siapa pun. Bila HP hilang, hapus tokennya di halaman GitHub yang sama.
